# Bảng đổi id v2

Một lần đổi id duy nhất để khớp dàn ý 12 chương (`docs/outline-v2.md`). Nội dung bài không đổi. Id bài nào không có trong bảng thì giữ nguyên. Tiến trình lưu ở trình duyệt dùng id cũ nên đã tăng lên phiên bản 2 và bỏ qua dữ liệu cũ. Bài boss cũ `c6-boss` (JOIN ba table) thành `c7-boss` và nằm ở bài `c7-b5`.
